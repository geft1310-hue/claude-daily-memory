Один продукт · одна настройка · постоянная память

NotebookLM помнит то, что узнал Claude Code.

Claude Daily Memory превращает отобранную полезную работу из всех проектов в одну растущую и очищенную память NotebookLM — и даёт Claude полный локальный доступ ко всем блокнотам и материалам аккаунта.

Постоянный источник памяти подключается и обновляется автоматически. Без второго установщика и ручного ежедневного обновления источника.

Один непрерывный цикл памяти

Проекты Claude Code → полезные результаты → очищенная дневная память → документ Google → автоматически обновляемый постоянный блокнот NotebookLM

Память между сессиями

Планы, решения, находки, итоги проверок и незавершённые задачи сохраняются без копирования целых разговоров.

Все блокноты

Тот же локальный MCP позволяет Claude использовать все блокноты, источники, чат, заметки, исследования и общий доступ.

Материалы Studio

Создание, отслеживание, переименование и скачивание поддерживаемых материалов аккаунта.

Безопасный повтор

После сбоя обновления день остаётся незавершённым; повторный запуск не дублирует запись Google.

Одна установка

git clone https://github.com/geft1310-hue/claude-daily-memory.git
cd claude-daily-memory
./install.sh

Одно окружение содержит приложение, Google Drive/Docs, Gemini, браузерную поддержку, закреплённый клиент NotebookLM и локальный MCP. Timer остаётся выключенным, пока единая настройка не завершит Google OAuth, вход и привязку NotebookLM, сохранение ключа Gemini, обновление источника и регистрацию MCP.

Границы приватности

Без сбора стенограмм

Автоматический процесс не читает сырые стенограммы Claude, полные запросы/ответы, команды, данные инструментов, Gmail и произвольные файлы.

При сомнении — отказ

Каждый материал и итог проверяются до сетевого запроса. Неопределённость отменяет отправку.

Ключи остаются локально

Google и Gemini используют системный keyring. Браузерная сессия NotebookLM остаётся на компьютере и исключена из Git.

Только локальный stdio

Без удалённого NotebookLM MCP, HTTP listener, переноса cookies в облако, master token и экспорта credentials.

Честная реализация

Доступ к пользовательскому NotebookLM использует закреплённую MIT-зависимость notebooklm-py[browser,mcp]==0.8.0 и внутренние веб-RPC Google. После изменений Google может понадобиться обновление или новый локальный вход. Удаление и расширение общего доступа требуют предварительного просмотра и отдельного явного подтверждения.
