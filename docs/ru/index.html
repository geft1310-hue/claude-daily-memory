Claude Code → дневная память → NotebookLM

Перестаньте терять лучшую работу с ИИ.

Claude Daily Memory превращает полезные планы, решения, находки и незавершённые задачи из всех терминалов и проектов Claude Code в одну растущую базу знаний NotebookLM.

Claude Code выполняет работу. Claude Daily Memory сохраняет полезные результаты. NotebookLM помогает искать, связывать, понимать и использовать их снова.

Боль: контекст теряется

Сессия закончилась

Важное вчерашнее решение уже недоступно в сегодняшнем терминале.

Проекты разрознены

Исследования, планы и компромиссы разбросаны по репозиториям и чатам.

Ручные итоги не работают

Переносить полезное в базу знаний после каждой сессии утомительно и легко забыть.

Стенограммы не подходят

Они шумные, неудобные для повторного использования и могут содержать пароли и личные данные.

Второй мозг из настоящей работы

Все терминалы и проекты Claude Code → полезные результаты → одна дневная память → документ Google → NotebookLM

Документ подключается к NotebookLM один раз. По мере накопления знаний NotebookLM становится историей того, что вы сделали, решили, выяснили и ещё не закончили.

Задавать вопросы и создавать конспекты, отчёты, FAQ, карты знаний, аудиообзоры и другие материалы, доступные в вашем аккаунте.

Автоматически, но избирательно

Сохраняются результаты

Отобранные планы, решения, заметки, отчёты, итоги проверок и безопасная общая активность.

Отбрасывается шум

Без приветствий, повторных объяснений, команд, полных запросов, полных ответов и данных инструментов.

Все терминалы сразу

Одновременные сессии работают безопасно благодаря блокировкам файлов и повторяемому результату.

Без ежевечернего ритуала

Ежедневная задача готовит память сама, без копирования разговоров вручную.

Рассчитано на настоящие проекты

Стенограммы не читаются

Автоматический сбор не открывает файлы стенограмм Claude Code.

Двойная проверка

Каждый материал и вся дневная память проверяются до сетевых запросов.

Официальное подключение

API Google Drive и Docs с узким разрешением drive.file, токен — в системном хранилище паролей.

При сомнении — отказ

Ошибка чтения, сбой проверки, отсутствие доступа или подозрительная строка отменяют отправку.

Установка

git clone https://github.com/geft1310-hue/claude-daily-memory.git
cd claude-daily-memory
./install.sh

Таймер остаётся выключенным до настройки Google. Сначала сделайте локальный пробный запуск, просмотрите результат, затем создайте документ по инструкции на русском и добавьте его в NotebookLM как источник Диска.

Открытый проект

Помогите улучшить установку, поиск секретов, работу с NotebookLM, расписание в macOS и Windows, доступность и переводы. См. руководство для участников и политику безопасности.

Лицензия Apache-2.0. Проект не связан с Anthropic и Google и не одобрен ими. Claude, Gmail, Gemini, Google Drive и NotebookLM — товарные знаки соответствующих владельцев.
