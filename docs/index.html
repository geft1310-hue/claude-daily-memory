Claude Code → daily memory → NotebookLM

Stop losing your best AI-assisted work.

Claude Daily Memory turns useful plans, decisions, findings, and unfinished threads from every Claude Code terminal and project into one growing NotebookLM knowledge base.

Claude Code does the work. Claude Daily Memory preserves the useful results. NotebookLM helps you search, connect, understand, and reuse them.

Get it on GitHub Quick start AI-readable facts

The context-loss problem

Sessions end

A valuable decision made yesterday is no longer available in today's terminal.

Projects fragment

Research, plans, and trade-offs are scattered across repositories and conversations.

Manual summaries fail

Copying useful work into a knowledge base after every session is repetitive and easy to forget.

Raw transcripts are wrong

They are noisy, difficult to reuse, and may contain credentials, personal data, commands, and private files.

A second brain built from actual work

All Claude Code terminals and projects → useful outcomes → one clean daily memory → Google Doc → NotebookLM

Connect the generated Google Doc to NotebookLM once. As daily knowledge accumulates, NotebookLM becomes a searchable history of what you built, decided, discovered, and still need to finish.

Recover decisions

Ask what was chosen, what alternatives were rejected, and why.

Return to old projects

Generate a briefing with the latest state, open threads, and important context.

Connect projects

Find repeated problems, reusable solutions, shared dependencies, and conflicting assumptions.

Use NotebookLM features

Ask questions and create summaries, reports, FAQs, study materials, mind maps, audio overviews, and other outputs available in your NotebookLM account.

Automatic—but selective

Remember useful outcomes

Curated plans, decisions, notes, reports, verification results, and safe high-level activity.

Ignore conversation exhaust

No greetings, repeated explanations, raw commands, full prompts, full responses, or tool input/output.

Work across terminals

Concurrent sessions contribute safely through file locks, deterministic output, and project identity merging.

No daily ritual

A staged system timer prepares one daily memory without requiring an end-of-session copy-and-paste routine.

Designed for real project data

Raw transcripts stay untouched

The automatic pipeline never reads Claude Code transcript JSONL files.

Secrets are checked twice

Each selected artifact and the complete daily memory are scanned before networking.

Official Google connection

Drive and Docs APIs use the narrow drive.file scope. Tokens belong in the operating-system Secret Service.

Fail closed

Malformed data, scanner errors, missing credentials, or ambiguous secret-like content stop the upload.

Install

git clone https://github.com/geft1310-hue/claude-daily-memory.git
cd claude-daily-memory
./install.sh

The timer remains off until Google OAuth setup is complete. Start with a local dry run, review the Markdown, create the Google Doc through the official setup flow, and then add that document to NotebookLM as a Drive source.
