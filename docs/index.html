Claude Daily Memory

Long-term memory for Claude Code that combines work across terminals and projects without uploading raw transcripts, tool data, passwords, tokens, or private files.

View on GitHub Quick start AI-readable project facts
Claude Code terminals → local curated digest → secret scanner → Google Doc → NotebookLM Drive source

Built for safe AI memory

No raw transcripts

Only allowlisted lifecycle metadata and curated Markdown artifacts enter the pipeline.

Secret-aware

Known token formats, private keys, cookies, environment assignments, personal data, and suspicious high-entropy strings are blocked or redacted.

Multiple terminals

File locks, HMAC aliases, deterministic output, and idempotent document markers support concurrent Claude Code sessions.

Official Google APIs

Optional export uses Drive and Docs APIs with the narrow drive.file OAuth scope and operating-system Secret Service.

NotebookLM-friendly

Add the generated Google Doc once as a normal Drive source. No private APIs, browser automation, or copied cookies.

Reversible Gmail cleanup

Exact rule matches can move to Trash without repeated prompts. Permanent deletion is intentionally unsupported.

Install

git clone https://github.com/geft1310-hue/claude-daily-memory.git
cd claude-daily-memory
./install.sh

Google upload stays disabled until you explicitly complete OAuth setup. Start with a local dry run and review the generated Markdown.
