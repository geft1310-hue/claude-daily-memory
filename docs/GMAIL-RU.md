# Доступ к Gmail и очистка почты

**Русский** · [English](GMAIL.md)

Claude Daily Memory **не копирует письма** в дневную память. Доступ к Gmail — отдельное интерактивное подключение.

Рекомендуемые разрешения:

- читать письма и ярлыки;
- готовить и отправлять письма по однозначному заданию;
- ставить ярлыки и перемещать подходящие письма в корзину;
- не удалять письма безвозвратно и не очищать корзину.

## Очистка без повторных подтверждений

Правило очистки — это заранее данное разрешение перемещать точные совпадения в корзину. Все положительные условия правила должны совпасть. Исключения имеют приоритет. Если поля не хватает или совпадение сомнительное, письмо остаётся во входящих.

Безопасные поля правила:

- адрес отправителя или домен отправителя;
- регулярное выражение для темы;
- обязательные ярлыки Gmail;
- минимальный возраст письма;
- исключённые отправители и исключённые темы.

После пакетной уборки показывается только сводка по правилам: название правила и количество перемещённых писем. Тексты писем не попадают ни в отчёт, ни в дневную память.

Пример файла правил: [`gmail-cleanup.example.yml`](gmail-cleanup.example.yml).

## Что это разрешение не включает

- безвозвратное удаление писем;
- очистку корзины;
- изменение фильтров и правил самого Gmail;
- массовую рассылку;
- отправку писем без вашего явного задания.

Ошибка обратима: письмо остаётся в корзине, и его можно вернуть.
